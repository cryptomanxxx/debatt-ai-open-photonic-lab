## Manual setup workflow
Set repository variable CF_ACCOUNT_ID to the Cloudflare account ID and temporary repository secret CF_WEBHOOK_SETUP_TOKEN to an account-scoped Workers Scripts Edit API token. This permission can affect other Workers in that account; revoke the token and remove the GitHub secret immediately after setup. Inspect mode lists matching Google registrations without creating anything. Create mode requires explicit confirmation of disabled Google billing, first attempt on main, no existing matching registration, and existing GITHUB_TOKEN on the Worker. It transfers the one-time signing secret directly to Cloudflare. No raw response or real secret is logged or uploaded. If any create attempt fails, inspect before retrying; registration may have succeeded even if secret transfer failed. Recover existing registration by manual rotation, not duplicate creation. Free Tier compatibility remains unverified. Leave CONFIRM_FREE_PROJECT and AG_ROUTES unset until delivery is tested. No research is submitted.
