# Chip 14 · Photonic In-Memory Computing

Serve the repository's `web/` directory over HTTP and open `/chip14/`. In Sites the selector route is `#photonic-circuit-lab/in-memory-computing`.

Edit one signed weight at a time and vary the four inputs. The selected weight's row shows every individual signed product and its optical power rails. The result table compares all four outputs against an electronic reference. Try the coarse-detector preset to inspect the change in agreement.

See the [model, references, tests and Sites instructions](../opa-w/README.md).
