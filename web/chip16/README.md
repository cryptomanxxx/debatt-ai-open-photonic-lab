# Chip 16 — Photonic Ray Tracing Accelerator

Standalone educational prototype. Chip 13–15 remain reserved concepts in OPA-W. Open index.html in a modern browser; no dependencies or network requests. This prototype shows a 2D cross-section of a ray/box test, not the published four-MZM 3D circuit. The quantized test is a numerical proxy, not a device model. Site integration is a separate task requiring the current Sites source and testing. See [OPA-G](../../research/OPA-G-ROADMAP.md) and [OPVR](../../research/OPVR-ROADMAP.md).

Manual checks: angle 0°, origin y=0 hits; angle 0°, origin y=2 misses; negative direction misses; quantization can change classification near an edge. Check keyboard access, phone layout, and reference/proxy labels. Future work: 3D BVH, independent tests, optical encoding and calibrated energy accounting.
