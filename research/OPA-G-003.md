# OPA-G-003 — Four-MZM behavioral circuit

First single-carrier normalized circuit model; not a fitted TFLN device. Source: Zhang et al., Nature Communications (2025), DOI 10.1038/s41467-025-61234-x, Supplementary Notes 1–3 (especially Fig. 2). Use corrected signed determinant from [source audit](OPA-G-002-SOURCE-AUDIT.md). The source's high-speed TFLN experiment used electronic preprocessing; our four serially paired signed modulators are a behavioral realization of the arithmetic, not a claim of reproducing the exact laboratory signal loading.

Reuse the ideal complex transfer matrix in simulations/circuit/mzi.py (opa-mzi-reference); remove common phase to compare its null-port field against sin(theta/2). Existing lnoi400 PDK cells and EO001/002 are useful for future device-level parameterization; they do not establish measured active modulator tolerances for this architecture. No new PDK component or layout is proposed.

Electronic reflection and parallel/forward guards precede optics. Normalize spatial and directional factors by separate positive per-ray maxima; the determinant sign is invariant. Four operands x are in [-1,1]. Each MZM field is sin(s*x+b)/s, where s and b are half-differential phases in radians; the normalization absorbs ideal gain, not physical optical amplification. Two serial products combine coherently with relative phase and power loss in dB (field attenuation 10^(-loss/20)). An ideal balanced reference receiver yields Re(z) from the difference of squared magnitudes of 1+z and 1-z divided by 4. This is normalized algebra, not absolute photocurrent or optical power. Gaussian additive noise is in normalized receiver units.

Sweep half-phase drive 0.05/0.15/0.30/0.60 rad; static independent bias bounds 0.002/0.01/0.03 rad; relative branch phase 0.05/0.15/0.30 rad; differential branch loss 0.25/1/3 dB; additive noise standard deviation 0.001/0.005/0.02; combined scenario. All are illustrative, not empirical device specifications. Three seeded repeats per scenario. Fit scalar gain and offset using 8192 independent uniform operand calibration samples, estimate 99th percentile absolute calibration residual, report coverage on 8192 separate uniform operand validation samples. Coverage is empirical, not a safety guarantee, nor necessarily transferable to geometry. No author PSO calibration reproduced.

Evaluate G-001 workloads, exhaustive integer grid and translated synthetic boxes. Report ray-level FP/FN, hit/miss denominators, guard counts, side-test counts, and electronic fallback count. Compare zero-threshold binary readout with hypothetical confidence windows 0/0.005/0.02/0.05/0.1 and empirical residual q99, using identical noisy values per threshold. If any side is ambiguous, exact electronic fallback returns the reference classification. This deliberately optimistic fallback requires extra comparator thresholds or analog readout; it is not implementable with only one fixed sign bit. No conversion cost or speed benefit inferred.

CI gates: ideal signed field agrees with repository MZI matrix, signed receiver controls, ideal normalized geometry agrees with exact oracle (tiny float-zero tolerance in ideal check only), finite positive calibration gain, count bounds, fallback cannot add errors, sweep coverage. No accuracy requirement on nonideal scenarios; report negative results. Run python simulations/graphics/photonic_side_v004.py. Archive result.json and results.csv with actual CI provenance. Absolute power, measured calibration, RF bandwidth, receiver offsets and drift, device-specific models and system energy remain open. G-003 is a first behavioral study, not full calibrated uncertainty validation.
