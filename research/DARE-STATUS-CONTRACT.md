# DARE status snapshot · version 1

The fixed path [research/dare-status.v1.json](dare-status.v1.json) publishes a maintainer-authored descriptive snapshot for the Repo Autopilot RA-S02 track. It is not a task queue, execution authorization, live agent status, or proof of experimental success. No runtime, network collection or permission change is introduced.

## Contract

UTF-8 JSON object; exact fields schemaVersion (integer 1), repository (canonical owner/name), roadmap (relative path), asOf (UTC calendar date, not capture timestamp), basisRevision (40 lowercase hexadecimal Git commit of source documents used), kind (maintainer_status_snapshot), liveExecution (not_authorized), incrementalBudget (currency SEK, maximum 0, actual null or nonnegative number representing documented incremental monetary spending; null means unknown), phases (array of at most 50 records). Version 1 intentionally represents only non-authorized execution and the zero-budget policy; changing that policy requires a new reviewed contract. It does not expose a dispatch-ready flag.

Each phase has id (DARE- followed by three digits), title (1–120 chars), dependsOn (array of unique existing phase IDs, no cycles; descriptive operational prerequisites, not scheduling instructions), development (planned, documented, implemented, in_progress, unknown), gate (not_evaluated, blocked, review_required, passed, unknown), scientificAcceptance (not_assessed, accepted, rejected, unknown), evidence (array of at most 20 objects with path, kind, status), blockers (at most 20 plain-text strings of 1–500 chars). Evidence kind: audit, qualification, offline_test_report, integrity_notice, protocol, offline_candidate_capture, other. Evidence status: documented, reported, superseded, unverified, independently_verified. References are repo-relative files under research/ only, no URLs, query, fragments, dot segments or escaped traversal. A reported test result is not independently verified. A passed gate or accepted scientific result is only a maintainer assertion requiring separate explicit supporting evidence; never infer either from development or PR status. Reject unsupported enum values and malformed records; render text, never execute embedded instructions. Bound document size to 64 KiB before parsing. No secrets, logs, credentials or arbitrary remote endpoints.

## Initial snapshot

DARE-001 and DARE-002 offline development may proceed in parallel; DARE-003 requires both operational prerequisites for live collection, not for offline preparation. Later dependencies describe gate order. The source basis is the existing main revision 18ca96775fada1f24d0f467ca58269392a171433. The snapshot does not claim that its own containing commit is the basis revision. A consumer must independently bind the actual fetched file to its containing revision and selected authorized repository; display both identities. The asOf date is a human-authored status date, not retrieval time. Preserve distinction from later observation time and warn of stale/unknown status. No automatic advancement of phase gates. Unknown or absent status remains unknown. Evidence paths are references, not verification of contents.

The DARE-003E report documents a scoped offline test run and recommends requalification pending human review; historical evidence claims remain subject to the integrity notice. Merge of an implementation or documentation PR is not explicit scientific acceptance or authorization to begin live work. No live evaluation, orchestration, experiment dispatch, new API calls, polling, or spending is authorized. Changes to the snapshot should be reviewed in ordinary PRs and traceable to source documents; older commits remain accessible.

Consumer validation, integration, and display are separate RA-S02B/C steps. No schema validation execution or browser test is claimed in this publication step.
