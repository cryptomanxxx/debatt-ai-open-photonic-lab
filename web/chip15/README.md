# Chip 15 · Photonic Neural Network

Serve the repository's `web/` directory over HTTP and open `/chip15/`. In Sites the selector route is `#photonic-circuit-lab/stored-weight-network`.

Choose a layer and cell to edit its stored weight. Run inference and compare the detected linear values, hidden-layer activations and two output scores. The error preset adds quantization, optical attenuation, detector noise and weight drift. Activations and optical re-encoding between layers are modeled as electronic stages.

See the [model, references, tests and Sites instructions](../opa-w/README.md).
