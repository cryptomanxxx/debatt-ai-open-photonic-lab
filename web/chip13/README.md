# Chip 13 · Photonic Weight Memory

Serve the repository's `web/` directory over HTTP and open `/chip13/`. In Sites the selector route is `#photonic-circuit-lab/weight-memory`.

Choose a 4 × 4 or 8 × 8 array and one cell, set a target level and apply a write pulse. Stop the lasers, then start an optical read to compare intended and decoded levels. The 16-level preset fills a 4 × 4 grid with one example of each nominal level. The weak-pulse preset demonstrates a request below the model's write threshold.

See the [model, references, tests and Sites instructions](../opa-w/README.md).
