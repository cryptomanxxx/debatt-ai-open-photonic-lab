Chip 16 — Photonic Ray Tracing Accelerator

Explore how a ray-box intersection can reject irrelevant regions of a scene. This is a 2D teaching model, not a physical optical simulation or a GPU benchmark.

The reference uses a forward-ray slab test. The proxy rounds origin and direction components to a fixed fractional grid before repeating the same test. It does not reproduce the optical side-function algorithm, modulator physics or measured error rate.

Research inspiration: Zhang et al., Nature Communications (2025). The published device accelerates ray-box tests using TFLN modulators and coherent readout. Full rendering requires additional stages.
